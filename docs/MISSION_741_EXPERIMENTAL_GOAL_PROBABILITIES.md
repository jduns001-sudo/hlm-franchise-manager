# Mission 741: Experimental goal probabilities

This controlled research-only module converts Mission 740's fractional expected goals into independent Poisson probability masses for 0 through 6 goals. These are fictional assumptions, not NHL-calibrated probabilities or a prediction of actual scores. Tail mass beyond six goals is deliberately omitted and not renormalized. Incomplete roster evidence yields null distributions for both teams. The model never chooses a winner, creates a game result, changes standings, updates a save, or authorizes simulation. No Front Office, Phase 10 demo, or Phase 11 import integration.

Run `node hlm-phase10-experimental-goal-probabilities.test.js`.
